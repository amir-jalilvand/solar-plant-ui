# سامانه مدیریت و نظارت بر نیروگاه‌های خورشیدی انشعابی — نمونه اولیه رابط کاربری

نمونه اولیه (Prototype) رابط کاربری فارسی و راست‌به‌چپ برای پلتفرمی که چرخه کامل احداث نیروگاه خورشیدی انشعابی را از ثبت درخواست تا تحویل و خدمات پس از فروش مدیریت می‌کند و ابزار نظارتی ساتبا را فراهم می‌آورد.

- **پشته:** React 19 + TypeScript + Vite + Tailwind CSS 4 + React Router 7
- **بدون بک‌اند:** همه داده‌ها Mock و در حافظه هستند
- **فارسی و RTL:** اعداد فارسی، تاریخ شمسی، واحد تومان، فونت Vazirmatn
- **حالت روشن/تیره** و ریسپانسیو با اولویت موبایل

## اجرا

```bash
pnpm install
pnpm dev
```

سپس <http://localhost:5173> را باز کنید. برای بررسی نسخه نهایی:

```bash
pnpm build
pnpm preview
```

## نقش‌ها

برای جابه‌جایی بین نقش‌ها از انتخابگر «مشاهده به‌عنوان» در سایدبار استفاده کنید. هر نقش منو و داشبورد خودش را دارد:

| نقش | مسیر شروع | تمرکز |
| --- | --- | --- |
| متقاضی | `/applicant` | وضعیت پروژه، اقدام بعدی، قرارداد و اقساط، پشتیبانی |
| نصاب / پیمانکار | `/installer` | پروژه‌های ارجاعی، پیشرفت اجرا، مدارک فنی |
| کارشناس فنی / ناظر | `/inspector` | صف بررسی مدارک و آزمون‌ها، چک‌لیست فنی |
| مدیر سکو | `/admin` | شاخص‌ها، جدول/کانبان پروژه‌ها، مالی، کاربران، گزارش‌ها |
| ناظر ساتبا | `/satba` | نظارت خواندنی، گزارش عملکرد، وضعیت اتصال API |

## امکانات دمو

- **سوئیچر نقش** برای دیدن همه پنل‌ها بدون ورود واقعی (صفحه `/login` هم موجود است).
- **انتخابگر «حالت صفحه»** در نوار بالا: عادی / بارگذاری / خالی / خطا — برای دیدن چهار حالت هر صفحه.
- **پارامترهای URL** برای دمو و تست: `?role=satba`، `?theme=dark`، `?demo=empty`.
- **حالت تیره** با ذخیره در `localStorage`.
- **اقدامات تعاملی:** تأیید/رد مدرک با دلیل اجباری، قبول/رد پروژه توسط نصاب، ویزارد ثبت درخواست با اعتبارسنجی، ثبت بازخورد، همگام‌سازی آزمایشی API.

## ساختار پروژه

```
src/
  components/     کامپوننت‌های مشترک (Shell، Stepper، Timeline، جدول‌ها، UI، نمودار)
  pages/          صفحات هر نقش
  lib/
    types.ts      مدل داده‌ها
    data.ts       داده Mock و توابع دسترسی (نقطه اتصال به API واقعی)
    labels.ts     برچسب‌ها، مراحل، رنگ وضعیت
    format.ts     اعداد فارسی، تومان، تاریخ شمسی
    demo.tsx      شبیه‌سازی کوئری و چهار حالت صفحه
    role.tsx      نقش فعال
    theme.tsx     حالت روشن/تیره
```

## داده و اتصال به API

همه داده‌ها در `src/lib/data.ts` ساخته می‌شوند: ۱۷ پروژه در همه مراحل چرخه عمر (شامل پروژه متوقف، مدرک رد‌شده و پرداخت معوق)، ۵ نصاب، ۸ کاربر، قرارداد، اقساط، تجهیزات، گزارش پیشرفت، آزمون، تیکت، بازخورد و اعلان.

برای اتصال به API واقعی کافی است توابع همین فایل با لایه کوئری (مثلاً TanStack Query) جایگزین شوند؛ کامپوننت‌ها تغییری لازم ندارند.
